# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be respectful, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment, insults and personal attacks are not tolerated.

## Reporting

If you experience or witness unacceptable behavior, please report it privately through [GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) or by contacting the maintainer via their GitHub profile. All reports will be reviewed and handled confidentially.
